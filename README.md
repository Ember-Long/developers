## 怎么留名？

点击上方「提 PR 留名」，在表格末尾添加自己的一行，然后提交 Pull Request。管理员合并后，你的名字就会出现在这里。

格式如下，把示例换成你自己的信息。没有项目也可以，最后一格留空即可。

```markdown
| 你的昵称 | [@你的用户名](https://github.com/你的用户名) | [项目名](https://你的项目链接) |
```

不熟悉 PR？点「开 Issue 留名」，填写昵称和 GitHub，由管理员录入。只留自己的名字，不用先贡献代码；开源项目、工具、还没写完的东西，都可以放。
